# Dashboard_e_Relat-rio_E-commerce

# Análise de Vendas de E-commerce em Excel

Análise exploratória de 5.000 pedidos de uma loja virtual, feita no Excel. O projeto reúne tabelas dinâmicas, um dashboard interativo com KPIs, gráficos e segmentação de dados, e um relatório com as principais conclusões.

## O que foi analisado

- Receita por categoria, forma de pagamento, região e ano
- Ticket médio e desconto médio
- Avaliação dos clientes

## Principais conclusões

- A receita total foi de R$ 5,11 milhões, com ticket médio de R$ 1.021,96.
- Eletrônicos e Roupas lideram a receita, e Beleza fica em último.
- O cartão é a forma de pagamento mais usada (cerca de 46% da receita).
- As regiões têm receita equilibrada, entre 24% e 26% cada.
- O desconto médio é de 18%, e a avaliação média fica em torno de 3 em 5.

## Ferramentas

Excel: tabelas dinâmicas, segmentação de dados, gráficos e dashboard.

*A base de dados é sintética e foi usada para fins de estudo.*
